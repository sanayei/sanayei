# Amir Sanayei

I've shipped machine learning to production for eleven years: drive-failure detection at Western Digital, revenue forecasting at AWS, and title automation at First American. Underneath all of it sat the same question: when can you trust the model, and when does a human need to check?

Now I research that question for large language models: how to tell which model is actually better when the labels, the judges, and the evaluation budget are all imperfect.
